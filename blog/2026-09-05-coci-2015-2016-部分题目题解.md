## [B. SLON](https://www.luogu.com.cn/problem/P7229)
### 前言
> 这是一道很考验耐心与代码实现的问题。

### 思路
其实思路可以说没有丝毫难点，完全就是题目怎么说我们怎么做，具体来说，就是先将题中给的字符串化成 $kx+b$ 这样的表达式，然后求使得 $kx+b \equiv p \pmod{m}$ 的最小的 $x$。前面的部分考验用常见的弹栈来写，但这次的代码中用到了 $ai$ 给的一种递归写法（个人觉得更简洁易读一些），具体实现看代码应该能看懂。不过需要注意的一点是，这道题用递归写法可能会更好的原因是运算符简单而少，所以不需要怎么扩展，代码也短一些，在一些运算符多的题目中还是用弹栈比较稳定安全。后面的部分可以用扩展欧几里得来求解。

### 扩展欧几里得部分

表达式解析后可以表示为：

$$
ax+b
$$

题目要求：

$$
ax+b\equiv P\pmod M
$$

移项得：

$$
ax\equiv P-b\pmod M
$$

令：

$$
r=(P-b)\bmod M
$$

设：

$$
g=\gcd(a,M)
$$

同余方程有解当且仅当：

$$
g\mid r
$$

扩展欧几里得算法可以求出：

$$
ax_0+My_0=g
$$

若：

$$
r\not\equiv0\pmod g
$$

则无解。

否则，将方程约去 $g$，得到：

$$
\frac agx+\frac Mg y=\frac rg
$$

此时 $x_0$ 是 $\frac ag$ 在模 $\frac Mg$ 意义下的逆元，因此答案为：

$$
x\equiv\frac rg\cdot x_0
\pmod{\frac Mg}
$$

最后将答案调整到最小非负整数范围即可。

```cpp
#include<iostream>
#include<algorithm>
#include<string>
#include<cctype>
using namespace std;
typedef long long ll;

string s;
int pos;
ll P,M;
struct Val{ll a,b;};

int priority(char op)
{
    if(op=='+'||op=='-') return 1;
    if(op=='*') return 2;
    return 0;
}

Val calculate(Val left,Val right,char op)
{
    if(op=='+'){
        return {(left.a+right.a)%M,(left.b+right.b)%M};
    }
    if(op=='-'){
        return {(left.a-right.a+M)%M,(left.b-right.b+M)%M};
    }
    return {(left.a*right.b+left.b*right.a)%M,left.b*right.b%M};
}

Val parse(int minPriority=1)
{
    Val left;
    if(s[pos]=='x'){
        pos++;
        left={1,0};
    }else if(s[pos]=='('){
        pos++;
        left=parse();
        pos++;
    }else{
        ll num=0;
        while(pos<(int)s.size()&&isdigit(s[pos])){
            num=(num*10+s[pos]-'0')%M;
            pos++;
        }
        left={0,num};
    }
    while(pos<(int)s.size()&&s[pos]!=')'){
        char op=s[pos];
        int currentPriority=priority(op);
        if(currentPriority<minPriority) break;
        pos++;
        Val right=parse(currentPriority+1);
        left=calculate(left,right,op);
    }
    return left;
}

ll exgcd(ll a,ll b,ll &x,ll &y)
{
    if(b==0){
        x=1;
        y=0;
        return a;
    }
    ll x1,y1;
    ll g=exgcd(b,a%b,x1,y1);
    x=y1;
    y=x1-a/b*y1;
    return g;
}

int main()
{
    ios::sync_with_stdio(0);
    cin.tie(0),cout.tie(0);
    cin>>s>>P>>M;
    Val res=parse();
    ll rhs=(P-res.b+M)%M;
    ll x,y;
    ll g=exgcd(res.a,M,x,y);
    if(rhs%g!=0){
        cout<<-1<<'\n';
        return 0;
    }
    rhs/=g;
    M/=g;
    if(M==1){
        cout<<0<<'\n';
        return 0;
    }
    x=(x%M+M)%M;
    cout<<rhs%M*x%M<<'\n';

    return 0;
}
```
