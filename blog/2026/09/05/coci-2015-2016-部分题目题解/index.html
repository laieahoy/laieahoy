COCI 2015/2016 部分题目题解

前言​

这是一道很考验耐心与代码实现的问题。

思路​

其实思路可以说没有丝毫难点，完全就是题目怎么说我们怎么做，具体来说，就是先将题中给的字符串化成 kx+bkx+bkx+b 这样的表达式，然后求使得 kx+b≡p(modm)kx+b \equiv p \pmod{m}kx+b≡p(modm) 的最小的 xxx。前面的部分考验用常见的弹栈来写，但这次的代码中用到了 aiaiai 给的一种递归写法（个人觉得更简洁易读一些），具体实现看代码应该能看懂。不过需要注意的一点是，这道题用递归写法可能会更好的原因是运算符简单而少，所以不需要怎么扩展，代码也短一些，在一些运算符多的题目中还是用弹栈比较稳定安全。后面的部分可以用扩展欧几里得来求解。

扩展欧几里得部分​

表达式解析后可以表示为：

ax+bax+bax+b

题目要求：

ax+b≡P(modM)ax+b\equiv P\pmod Max+b≡P(modM)

移项得：

ax≡P−b(modM)ax\equiv P-b\pmod Max≡P−b(modM)

令：

r=(P−b) mod Mr=(P-b)\bmod Mr=(P−b)modM

设：

g=gcd⁡(a,M)g=\gcd(a,M)g=gcd(a,M)

同余方程有解当且仅当：

g∣rg\mid rg∣r

扩展欧几里得算法可以求出：

ax0+My0=gax_0+My_0=gax0​+My0​=g

若：

r≢0(modg)r\not\equiv0\pmod gr≡0(modg)

则无解。

否则，将方程约去 ggg，得到：

agx+Mgy=rg\frac agx+\frac Mg y=\frac rgga​x+gM​y=gr​

此时 x0x_0x0​ 是 ag\frac agga​ 在模 Mg\frac MggM​ 意义下的逆元，因此答案为：

x≡rg⋅x0(modMg)x\equiv\frac rg\cdot x_0 \pmod{\frac Mg}x≡gr​⋅x0​(modgM​)

最后将答案调整到最小非负整数范围即可。

代码：

#include<iostream>
#include<algorithm>
#include<string>
#include<cctype>
using namespace std;
typedef long long ll;

string s;
int pos;
ll P,M;
struct Val{ll a,b;};

int priority(char op)
{
    if(op=='+'||op=='-') return 1;
    if(op=='*') return 2;
    return 0;
}

Val calculate(Val left,Val right,char op)
{
    if(op=='+'){
        return {(left.a+right.a)%M,(left.b+right.b)%M};
    }
    if(op=='-'){
        return {(left.a-right.a+M)%M,(left.b-right.b+M)%M};
    }
    return {(left.a*right.b+left.b*right.a)%M,left.b*right.b%M};
}

Val parse(int minPriority=1)
{
    Val left;
    if(s[pos]=='x'){
        pos++;
        left={1,0};
    }else if(s[pos]=='('){
        pos++;
        left=parse();
        pos++;
    }else{
        ll num=0;
        while(pos<(int)s.size()&&isdigit(s[pos])){
            num=(num*10+s[pos]-'0')%M;
            pos++;
        }
        left={0,num};
    }
    while(pos<(int)s.size()&&s[pos]!=')'){
        char op=s[pos];
        int currentPriority=priority(op);
        if(currentPriority<minPriority) break;
        pos++;
        Val right=parse(currentPriority+1);
        left=calculate(left,right,op);
    }
    return left;
}

ll exgcd(ll a,ll b,ll &x,ll &y)
{
    if(b==0){
        x=1;
        y=0;
        return a;
    }
    ll x1,y1;
    ll g=exgcd(b,a%b,x1,y1);
    x=y1;
    y=x1-a/b*y1;
    return g;
}

int main()
{
    ios::sync_with_stdio(0);
    cin.tie(0),cout.tie(0);
    cin>>s>>P>>M;
    Val res=parse();
    ll rhs=(P-res.b+M)%M;
    ll x,y;
    ll g=exgcd(res.a,M,x,y);
    if(rhs%g!=0){
        cout<<-1<<'\n';
        return 0;
    }
    rhs/=g;
    M/=g;
    if(M==1){
        cout<<0<<'\n';
        return 0;
    }
    x=(x%M+M)%M;
    cout<<rhs%M*x%M<<'\n';

    return 0;
}
