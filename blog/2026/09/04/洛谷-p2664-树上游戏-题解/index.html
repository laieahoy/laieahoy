洛谷 P2664 树上游戏 题解

修改
2026年9月4日 · 阅读需 6 分钟
laieahoy
管理员

这道题有两种比较好的做法，除了这篇题解所写的做法以外，还有一种点分治的做法，在这里。

先看题面，题目大意为给每个点一个颜色，记某点 iii 到点 jjj 的路径上经过的不同颜色数量为 sis_isi​，然后定义点 iii 的答案为 sumi=∑j=1ns(i,j)sum_i=\sum_{j=1}^ns(i,j)sumi​=∑j=1n​s(i,j)。

看到这样的题面，按照套路，我们会想到拆贡献，可以将点 iii 的答案转化为各种颜色对点 iii 的贡献之和，于是我们将视角焦点放到颜色上而不是每个点上。

于是我们先钦定研究某点 iii，对于某一种颜色 ccc，我们思考怎样的路径会使 ccc 对 iii 的答案产生贡献，因为我们只需计算这种颜色是否出现过，所以从点 iii 向外扩展的每条路径第一个颜色为 ccc 的点的外面的所有点都可以让 ccc 对 iii 产生贡献。

再继续思考一下，发现上述的操作其实就是找到包含 iii 的，包含的点中没有点的颜色为 ccc 的极大连通块，把视角放到整棵树上，就相当于将所有的颜色为 ccc 的点以及它们连的边删去，这样会余下一些连通块，根据我们刚刚的推导，对于连通块中的每一个点，颜色 ccc 能对它们造成贡献的路径就是某个点向连通块外的点连的路径，换句话说，设某个连通块的大小为 szszsz，那么颜色 ccc 对该连通块中所有点造成的贡献都是 n−szn-szn−sz。

意思是说，我们会对某个连通块的贡献进行整体加，于是可以想到树上差分，如下图所示，对于某个大小为 szszsz 的连通块中深度最小的点，即这个连通块最上方部分连接的颜色为 ccc 的点 uuu 的所有儿子 vvv 的点的权值上加 n−szn-szn−sz，然后再在 uuu 的各个儿子的子树中找到颜色为 ccc 的点，将它们的权值减 n−szn-szn−sz。

思路基本上确定了，现在的难点是如何得到每个连通块的大小。让我们想想一个连通块是怎么来的，其实就是一个颜色为 ccc 的点的儿子的子树再减去其中颜色为 ccc 的后代的子树，那么算大小时的流程也应该是一致的，可是如何知道那些儿子子树中颜色为 ccc 的后代节点的子树大小呢？我们是可以向下递归记录的，但这样就不得不枚举每种颜色，然后每次做一次递归，而不能在处理每个节点时一并处理它的子树中它所对应的颜色的问题。

为了不枚举每个颜色，我们可以维护一个桶 colorszcolorszcolorsz 来存某种颜色的信息，但是这个桶是全局的，所以我们求 vvv 的子树中颜色为 ccc 的点的子树的大小时就不能直接单纯记录，而需要转化。还是看上图，假设递归到 uuu 时桶中的 colorsz[ a[u] ]colorsz[\,a[u]\,]colorsz[a[u]]（aaa 为题目中给出的点的颜色），而向 v1v_1v1​ 递归完后回溯到 uuu 时，colorsz[ a[u] ]colorsz[\,a[u]\,]colorsz[a[u]] 就会加上 v1v_1v1​ 子树中所有颜色为 ccc 的节点的子树大小，那么两者的差值就是v1v_1v1​ 子树中所有颜色为 ccc 的节点的子树大小，于是连通块的大小就可以求出了。

但现在树上差分只是加的部分好做了，但在连通块的后代的颜色为 ccc 的节点处减的操作仍然不好做，但我们可以仿照刚刚的做法，对每个颜色开一个桶，来记录有哪些节点是这个颜色，但是怎么判断它是否在某个点的子树中呢，我们想到 dfsdfsdfs 序，它的性质可以让我们快速判断某个节点是否在某个点的子树中，那么减的部分也可以做了。

然而，我们发现一个问题，递归到某点时，我们实际处理的是它的子树，所以根节点（人为规定为 111）是不会被处理到的，我们需要对每种颜色再对根节点做一遍差分。最后，一遍 dfsdfsdfs 统计答案即可。

代码：

#include<iostream>
#include<algorithm>
#include<string.h>
#include<vector>
using namespace std;
typedef long long ll;

const int N=1e5+5;
int n,num,m,cnt;
int a[N];
bool vis[N];
int e[N<<1],ne[N<<1],h[N],idx;
int colsz[N],sz[N],dfn[N];
ll cf[N],f[N];
vector<int> ve[N];

void add(int a,int b)
{
    e[idx]=b,ne[idx]=h[a],h[a]=idx++;
}

void dfs1(int u,int fa)
{
    sz[u]=1;
    dfn[u]=++cnt;
    for(int i=h[u];~i;i=ne[i]){
        int v=e[i];
        if(v==fa) continue;
        int ts=colsz[a[u]];
        dfs1(v,u);
        int ns=sz[v]-colsz[a[u]]+ts;
        cf[v]+=ns;
        colsz[a[u]]+=ns;
        while(ve[a[u]].size()&&dfn[ve[a[u]].back()]>dfn[u]){
            cf[ve[a[u]].back()]-=ns;
            ve[a[u]].pop_back();
        }
        sz[u]+=sz[v];
    }
    colsz[a[u]]++;
    ve[a[u]].push_back(u);
}

void dfs2(int u,int fa)
{
    f[u]=f[fa]+cf[u];
    for(int i=h[u];~i;i=ne[i]){
        int v=e[i];
        if(v!=fa) dfs2(v,u);
    }
}

int main()
{
    ios::sync_with_stdio(0);
    cin.tie(0),cout.tie(0);
    memset(h,-1,sizeof h);
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>a[i];
        m=max(m,a[i]);
        vis[a[i]]=1;
    }
    for(int i=1,x,y;i<n;i++){
        cin>>x>>y;
        add(x,y),add(y,x);
    }
    dfs1(1,0);
    for(int i=1;i<=m;i++){
        if(vis[i]){
            num++;
            cf[1]+=n-colsz[i];
            for(int j=0;j<ve[i].size();j++){
                cf[ve[i][j]]-=n-colsz[i];
            }
        }
    }
    dfs2(1,0);
    for(int i=1;i<=n;i++) cout<<(ll)n*num-f[i]<<"\n";

    return 0;
}
